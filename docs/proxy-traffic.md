# 代理流量监控

在菜单栏显示实时上下行速度，点击「查看应用与网站流量」打开详情窗口。详情支持应用和域名排行、代理/直连/未知流向筛选、名称搜索，以及点击应用查看其域名。

## 连接

默认启用监控，读取本机 `http://127.0.0.1:9090` 的 Clash / Mihomo 控制接口。JetStream 当前配置可直接使用。其他端口或开启鉴权的客户端，可在应用设置的「代理流量」中填写接口地址和密钥，然后点击「应用」。密钥保存在 macOS 钥匙串中，不写入偏好设置或日志。

控制接口端口与 HTTP/SOCKS 代理端口不同：例如代理端口为 `7890`，控制接口可能为 `9090`。应用仅允许显式回环地址 `127.0.0.1` 或 `[::1]`，不会修改代理配置、切换节点或关闭连接。接口请求绕过系统代理，且不跟随重定向。

可以关闭流量监控、隐藏菜单栏网速，或选择同时显示 Codex 额度。

## 统计口径

- 总量来自代理内核的累计上传/下载计数，每秒采样，以计数增量除以实际间隔计算网速。顶部总量和曲线涵盖该内核处理的全部流量，包括 DIRECT；不等于代理订阅服务的计费流量。
- 首次连接建立基线，本次累计从此刻开始，不把内核启动以来的历史流量算进来。退出应用、关闭监控、更换接口或点击「重新统计」都会开始新会话。第一版不保存每日历史。
- 应用/域名排行根据连接增量采样，按累计上传与下载之和排序；「当前筛选累计」对应当前列表。应用内的辅助进程按外层 `.app` 合并，无法识别的应用单独列出。
- 网站代表连接域名或目标 IP，并非浏览器页面或标签页。未知流向单列，不默认视为代理流量。
- 快速结束的连接和最后一次采样后的尾部流量可能无法归属，列表不能保证与内核总量完全相等。「未归属」按总量与已采样明细的正差估算。
- 断线、代理计数归零或超过 5 秒的采样间隔重新建立基线，不累计未观测时段；界面提示中断，速度显示为不可用，不冒充零流量。曲线在这些时段断开。

## 资源边界

采集与额度查询相互独立，在后台执行，每次只保留最多 4 MB 的接口响应。曲线最多保留最近 5 分钟的 300 个采样点，明细保留 2,000 个应用/域名/流向组合；后续新组合按流向归入「其他」，不丢弃其已观测增量。过长的异常名称也归入「其他」。失败后采用 2～30 秒退避重试，取消监控会取消网络请求。

## 验证

有完整 Xcode 时运行 `./build.sh test`。`ProxyTrafficTests` 覆盖首次基线、重复连接、短暂消失、计数重置、断线与休眠间隔、流向筛选与应用下钻、缓存上限、响应边界、鉴权失败、回环地址限制及取消请求。
